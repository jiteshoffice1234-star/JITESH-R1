# 🚀 START HERE - Build Your APK

## ⚡ FASTEST METHOD (Recommended)

### On Windows:
```
Double-click: build-apk.bat
```

### On Mac/Linux:
```bash
chmod +x build-apk.sh
./build-apk.sh
```

### Or use Node.js (all platforms):
```bash
node build-apk.js
```

**That's it!** Your APK will be created as `SolarSystemExplorer.apk`

---

## 📋 What You Need

1. **Node.js** (v16 or higher) - [Download here](https://nodejs.org/)
2. **Android Studio** - [Download here](https://developer.android.com/studio)
3. **Java JDK 17** (included with Android Studio)

---

## 🎯 After Building

1. Find the file: `SolarSystemExplorer.apk`
2. Send it to your Android phone (USB, email, cloud, etc.)
3. On your phone:
   - Open Settings → Security → Enable "Unknown Sources"
   - Open the APK file
   - Tap "Install"
4. Launch the app from your home screen!

---

## 🆘 Having Issues?

### "Java not found"
- Install Android Studio
- Make sure JAVA_HOME is set in your environment

### "Android SDK not found"
- Open Android Studio
- Go to Settings → Appearance & Behavior → System Settings → Android SDK
- Install Android SDK

### "Gradle build failed"
- Open Android Studio
- Let it download all SDK components
- Accept all licenses

### Need more help?
Read the full guide: [BUILD_APK_GUIDE.md](BUILD_APK_GUIDE.md)

## 🌐 Alternative: No Android Studio?

Use **PWABuilder** (web-based, no installation needed):

1. Deploy this project to Vercel/Netlify (free)
2. Visit [pwabuilder.com](https://www.pwabuilder.com/)
3. Enter your deployed URL
4. Click "Build" → "Android"
5. Download your APK
