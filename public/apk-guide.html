No coding required! Generate APK directly from your deployed URL.

💻 Method 2: Build Locally Full Control

Build the APK on your computer using Android Studio or command line.

Prerequisites:

  • Install Node.js (v16+)
  • Install Android Studio
  • Accept Android SDK licenses

Build Steps:

# 1. Install dependencies
npm install

# 2. Build web app
npm run build

# 3. Add Android platform
npx cap add android

# 4. Sync web assets
npx cap sync android

# 5. Build APK
cd android
./gradlew assembleDebug
cd ..

# 6. Copy APK
cp android/app/build/outputs/apk/debug/app-debug.apk .
mv app-debug.apk SolarSystemExplorer.apk

💡 Or just run build-apk.sh (Mac/Linux) or build-apk.bat (Windows)

📱 Method 3: Android Studio Visual

Use Android Studio's visual interface to build and test.

  1. Run: npm run build && npx cap add android && npx cap sync
  2. Open Android project: npx cap open android
  3. Wait for Gradle sync to complete
  4. Click Build → Build Bundle(s) / APK(s) → Build APK(s)
  5. Click "locate" to find your APK file

📲 Installing the APK

  1. Transfer SolarSystemExplorer.apk to your Android device
  2. Open Settings → Security → Enable "Install from Unknown Sources"
  3. Open the APK file using a file manager
  4. Tap "Install" and wait for completion
  5. Open the app from your home screen!
